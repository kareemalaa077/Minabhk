# منبّهك — مشروع Flutter

تطبيق أندرويد عربي أولي لإنشاء تنبيهات بتاريخ ووقت محددين، وحفظها محلياً وجدولة إشعارات النظام.

## الحصول على APK بدون تثبيت Flutter على جهازك

تم تضمين GitHub Actions لبناء ملف APK سحابياً:

1. أنشئ حساباً على GitHub إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً (Repository) باسم `monabbihak`.
3. فك ضغط هذا المشروع، ثم ارفع **كل الملفات والمجلدات** إلى المستودع، بما فيها المجلد المخفي `.github`.
4. افتح تبويب **Actions** في المستودع.
5. اختر سير العمل **Build Android APK** ثم اضغط **Run workflow**. ويمكن أيضاً أن يبدأ البناء تلقائياً عند رفع الملفات إلى فرع `main`.
6. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل، وانزل إلى قسم **Artifacts**.
7. نزّل `monabbihak-release-apk.zip`، وفك ضغطه، وستجد `app-release.apk`.
8. انقل APK إلى هاتفك وثبّته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

## البناء محلياً

بعد تثبيت Flutter وAndroid SDK:
```bash
flutter create . --platforms=android --org com.example
flutter pub get
flutter build apk --release
```

ملف APK الناتج:
`build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات النسخة الأولية

- لا يحتاج التطبيق إلى حساب أو إنترنت أثناء الاستخدام.
- وافق على إذن الإشعارات، واسمح بالتنبيهات الدقيقة إذا طلب أندرويد ذلك.
- بعض الهواتف تفرض قيود بطارية؛ اختبر وصول التنبيه بعد إغلاق التطبيق.
- هذه نسخة أولية: لا تتضمن التكرار الدوري حالياً. كما أن استعادة التنبيهات بعد إعادة تشغيل الهاتف تحتاج اختباراً وتحسيناً إضافياً قبل الاعتماد عليها.
- سير العمل السحابي ينتج APK عند نجاح البناء؛ لا يمكن اعتبار الملف مختبراً على هاتفك إلا بعد تثبيته وتجربة التنبيهات فعلياً.
